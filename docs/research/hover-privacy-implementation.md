# WhiskyMac 0.0.7：悬停等待与手动局部显现

日期：2026-11-01。依据本轮用户选择：鼠标附近聚光式显现；仅手动隐私允许，自动保护全遮盖。

## 行为

- 设置 → 交互：悬停只提供无操作／预览。悬停等待时间支持输入和步进，0.1–5 秒，默认 0.7 秒；无操作时禁用时间控件。普通模式仍按等待时间打开原有完整预览。
- 旧 JSON 没有 hoverDelay 时补为 0.7；旧 hover 粘贴、复制、编辑、菜单改为无操作，避免迁移后悬停产生副作用。其他三种触发方式的动作不变；非法或非有限等待时间归一化，偏好仍在独立域保存。
- 手动隐私且悬停设置为预览时，卡片区域显示无内容轮廓。停留达到等待时间后只显现当前鼠标附近约 96 点直径的软边圆形区域，跟随鼠标移动，180ms 淡入；系统减少动态效果时取消淡入。离开卡片、关闭面板、修改悬停设置或自动保护介入即撤销。
- 自动保护正在生效（包括 unknown 预防遮盖和等待结束稳定）时始终全遮盖，不允许用鼠标揭示；自动保护结束后，若用户仍手动保护才恢复局部显现资格。自动检测虽开启但 scoped-clear 已稳定解除保护时，不妨碍独立的手动局部显现。
- 手动局部显现会真实显示在本机画面中，因此可能被录屏看到；它不提供“仅本机可见”的保证。敏感内存会话不纳入聚光区域，继续遵守独立的显式揭示规则。

## 实现边界

`InteractionBindings` 保存 hoverDelay 并执行兼容解码；`ItemCardView` 使用可取消的等待任务且只调用预览。
`PrivacyController.allowsSpotlight` 与整窗 isProtected 分离，并在整窗保护仍为 true 时也发布资格变化，
确保手动与自动保护叠加时立即收紧。

`HistoryViewStateStore` 保持保护态普通 state 为空，仅提供占位 UUID；payload 访问同时检查手动资格、
面板可见、悬停设置及有效记录身份。局部视图不经过普通菜单、复制、拖拽、编辑、Quick Look、
链接预览或大预览入口。关闭面板后，未完成任务也无法再读取内容。

`PrivacySpotlightView` 按需挂载占位卡片，每张卡片在鼠标停留后只读取一次对应 payload。
`SpotlightCanvas` 在绘制前先裁剪圆形区域，再加软边遮罩，不创建完整无遮盖的内容绘制表面。
正文和富文本在该小区域按纯文本摘要呈现，最多 4000 字符；文件只画文件名，链接只画普通文字。
图片仅悬停后在内存生成最长边 512 像素缩略图，原始数据上限 8 MiB；离开即释放，不写磁盘缓存。
本轮不是全富文本局部排版或滚动阅读器，完整阅读仍需用户主动关闭手动隐私。

整窗 AppKit 边界继续清空 AX 子节点；聚光 Canvas 及卡片不发布内容辅助功能文本，无复制、链接或拖拽操作。
存储原始历史不被占位符覆盖，不迁移或改写数据库内容。

- 374 项测试／59 个 suite 通过，可测试代码行覆盖率 90.74%（既有门槛 90%）。架构、严格格式、本地化和 diff 检查通过。
- 新增测试覆盖旧偏好迁移、动作限制、等待时间持久化与边界、手动／自动叠加、关闭面板后的访问拒绝、AX 遮盖、缩略图预算。
- 像素测试检查聚光中心不透明、区域外像素透明。合成截图在 `evidence/2026-11-01/hover-ui/manual-spotlight.png`。
- 既有检测器的 eventual 测试等待预算改为 15 秒：完整离屏界面测试可占用主线程超过原 3 秒；保留原行为断言，此调整不用于宣称检测延迟或性能指标。
