# 第 3、4、5 项：原生预览、交互与手动隐私

日期：2026-11-01。开发版：WhiskyMac 0.0.3，`dev.whisky.maclx`，macOS 15+。

## 原生视觉与预览

`GlassEffects.swift` 移除 `CAFilter`、动态私有方法与内部 layer 树查找，
保留公开 NSVisualEffectView、系统 material 和应用自身的 maskImage。
描边限制在自身形状内；减少透明度与动态效果继续读取系统偏好。

`RichTextGroups` 将同正文的富文本版本投射成一个模块，纯文本独立。
模块默认显示最近两种 RTF，`+x` 展开其余版本。正文、来源与时间保留原始
记录；分组不写数据库。键盘导航与模块序号采用相同的代表记录。

`HistoryViewStateStore` 只在详情打开时通过控制器读取原始内容；批量读取避免
逐版本扫描整个历史。`RichTextPreviewPane` 只解析已挂载详情，关闭后释放。
`RichTextView` 使用只读/可编辑 NSTextView；RTF 的字体、颜色、粗体、链接与
段落由原生解码保留。损坏或超过 8 MiB 的 RTF 回退为纯文本。编辑通过
`ClipboardController.editRich` 保存 plain + RTF，并支持 SQLite 重开与撤销。
列表仍使用轻量摘要，缩略图只为挂载卡片预热。原有图片、代码、链接和文件
预览路径保留；纯文本与代码详情读取完整内容。

## 可配置交互

`InteractionBindings` 保存四个独立映射：单击、双击、右键、悬停；六种动作
为粘贴、复制、预览、编辑、菜单、无动作。默认预览/粘贴/菜单/无动作。
SwiftUI exclusive tap 手势处理单/双击竞争；悬停等待 700ms，离开、关闭或
修改设置时取消。右键由限定在卡片区域内的 AppKit 事件适配器处理，省略号
菜单与 VoiceOver Actions 始终提供菜单入口。

多格式模块的复制、粘贴、编辑手势先打开版本选择，选择后执行请求动作。
预览中没有待执行动作时，Copy 按钮明确复制对应版本。置顶、删除、堆栈与
键盘直接操作仍针对最新版本，菜单有说明；分组卡片暂停直接拖拽，单版本
保持原有拖拽。粘贴记录之前的前台应用，尝试恢复焦点后校验目标再发送事件；
无辅助功能权限时保留剪贴板内容供手动粘贴，设置中有说明。快捷键注册失败
显示警示，避免将开关状态误报为注册成功。

## 手动隐私

`PrivacyController` 独立持久化手动保护偏好。菜单与设置都可切换；新增
可选全局快捷键，默认不注册，默认键位为 Control-Option-Command-P。
菜单栏图标和提示明确标为手动保护，不显示检测结果。

保护先于首次历史展示加载。`HistoryViewStateStore` 在保护态对外仅发布空
内容 DTO，清空详情、查询展示、待执行动作和编辑草稿；原始历史不被改写。
`HistoryPanelHosting` 重建显示树并将 AppKit 辅助功能子树替换为占位标签。
保护切换关闭详情窗口；受保护的预览也有独立占位分支。

统一动作门控阻止陈旧菜单、键盘与辅助功能回调继续导出内容；拖拽提供者和
延迟粘贴在执行时再次检查保护。LPMetadataProvider、Quick Look 请求取消，
代际校验拒绝过期完成回调；预览缓存清理并拒绝迟到写入。关闭保护后恢复
历史和查询状态。已经导出到其他应用或已经开始的系统拖拽不能追溯撤回，
应在展示或共享前开启保护。
