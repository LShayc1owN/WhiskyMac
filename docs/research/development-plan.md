# WhiskyMac：已确认的开发顺序与行为

更新：2026-11-01。合并项目最初需求、已审查源码及后续产品决定；本文件的
用户决定优先于早期调查中的建议。新增范围仍按阶段计划实施。

## 已完成

1. 独立开发版：`dev.whisky.maclx`、WhiskyMac、独立历史与设置；修复打包
   应用的设置域启动崩溃；两个全局快捷键首次关闭。
2. 数据一致性与可信基线：按 payload 与原始 RTF 字节共同去重；修复 SQLite
   同 ID 编辑、RTF 清除与撤销持久化；解决已知单复数与布局失败。

## 本轮已完成（0.0.3）

3. macOS 15 原生视觉与预览：以公开 API 调整视觉，移除上游私有视觉机制；
   按需加载完整富文本，只读预览与编辑分开。相同正文的富文本在同一模块内
   默认左右展示最近两种格式，其余用「+x」展开。纯文本保留为普通记录，
   不占富文本版本位；不预先解析所有列表记录的 RTF。
4. 可配置交互：单击、双击、右键、悬停分别配置粘贴、复制、预览、编辑、
   操作菜单或无动作；处理双击冲突、焦点恢复和辅助功能权限。需要确定版本
   时先让用户选择，再执行对应设置。右键被改绑后仍保留操作菜单的可达入口。
   本轮默认单击预览、双击粘贴、右键菜单、悬停无动作，均可修改；悬停延迟 700ms。
5. 手动隐私模式：菜单、可选全局快捷键及状态提示；遮盖文本、RTF、图片、
   链接、文件名、搜索、详情、提示与辅助功能输出；原始历史不受占位符影响。
## 已实现（0.0.5），真实客户端验收待完成

6. 敏感策略：明确不可记录的内容继续默认拒绝持久化。研究用户自选策略，
   临时揭示与自动重新隐藏；仅内存的敏感会话须与普通 DB、WAL、undo、日志、
   缩略图和缓存隔离，全局隐私保护优先于单条揭示。
7. 受限自动检测：可替换检测接口与隐私状态管理分开；公开 API、实验性实现
   与手动模式明确区分。自动开启由用户选择，不能清除手动保护。active、
   clearWithinCoverage、unknown 分开表达；尽快遮盖，稳定结束后才恢复。

## 一直适用的约束

- 目标系统为 macOS 15，使用 Swift、SwiftUI、AppKit 和公开系统 API；视觉
  简洁克制，保持上游架构和同步可能性。菜单栏支持自选 SF Symbol，后续考虑
  自定义导入、Template Image 及明暗适配；更新现有 NSStatusItem。
- 屏幕共享目标是本机展示占位符，不承诺仅对录制者隐藏。Mica、Hush 是研究
  资料；`CGSIsScreenWatcherPresent` 或其他私有 API 实际集成须另行确认。
  进程存在不等于共享，不宣称检测覆盖全部软件或保证没有泄露。
- 性能使用固定合成数据和 Instruments 基线验证，检查后台空闲、轮询、SQLite、
  缓存、窗口、NSImage、富文本、定时器与任务生命周期；不预设固定内存数值。
- 保留上游历史、版权及 GPL 与附加许可，标记修改。独立品牌素材与第三方资产
  授权在发行前核对；远程配置、推送及公开发行仍需明确授权。

第 3–5 项见 `stages-3-5-implementation.md`。第 6–7 项见
`stages-6-7-implementation.md`：敏感会话仅内存保留、显式揭示和自动隐藏；
自动检测默认关闭，仅用公开 AX API 检查 Zoom / Teams 特定工具栏标题。
规则经过合成测试，真实软件版本和语言尚未验证；其他共享／录屏不在覆盖范围。
下一轮优先做真实客户端与 VoiceOver 验收、Instruments 测量，再决定扩展适配器。
私有 API 和新检测范围仍须遵守上面的约束。
