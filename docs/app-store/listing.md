# WhiskyMac App Store draft

The machine-readable draft is metadata.json. Fill in release-config.json with
WhiskyMac's real public source repository, support and privacy policy URLs.
The metadata tool uses those addresses and rejects unfinished draft text.

Replace the version, release notes, review instructions, screenshots and privacy
disclosures with information verified against the actual submitted binary.
Use your own Apple developer account, application record, signing identities
and provisioning profile. GPL and the additional permissions do not supply
those Apple credentials or guarantee approval.

Publish the exact corresponding modified source and retain both exception
notices. See ../LICENSING.md and the two root README language versions.
The draft does not represent an existing WhiskyMac App Store submission.
